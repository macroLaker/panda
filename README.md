# Panda 🐼

Panda 是一个**个人生活记录 PWA**（渐进式网页应用），把生活装进口袋：

- **时间线**：按日期浏览所有记录，支持日历视图
- **日记**：记录每一天的生活点滴，可附照片
- **感悟**：随手记下灵感与想法
- **记账**：收支记录、分类统计、月度报表
- **待办**：轻量任务清单

> 🔒 **数据 100% 本地存储**：所有记录仅保存在你手机浏览器的 IndexedDB 中，**不上传任何服务器**，没有账号、没有云端，隐私完全由你掌控。

## 📱 iPhone 安装步骤

Panda 是网页应用，不需要去 App Store 下载，跟着下面 4 步就能像普通 App 一样使用：

1. 用 **Safari 浏览器**打开：**<https://macrolaker.github.io/panda/>**（必须用 Safari，不要用微信或其他浏览器内打开）
2. 点击屏幕底部中间的**分享按钮**（一个带向上箭头的方框 ⬆️）
3. 在弹出的菜单里向下滑动，找到并点击 **「添加到主屏幕」**，然后点右上角 **「添加」**
4. 回到手机主屏幕，会看到一个 Panda 图标——**以后每次都从这个主屏幕图标打开使用**

> ⚠️ **重要**：安装后请务必从**主屏幕图标**打开 Panda，不要再从 Safari 里打开。只有从主屏幕图标打开，才能获得全屏体验，数据也才能稳定保存在独立空间里。

## 💡 使用提示

- **PIN 锁**：首次打开会引导你设置 4 位数字 PIN 码，之后每次打开都需要输入，保护你的隐私。PIN 忘记后无法找回，请设置一个自己记得住的。
- **定期备份（强烈建议）**：建议**每月**在「设置」页里**导出一次 JSON 备份**。在 iOS 上点导出后会弹出系统分享面板，选择 **「存储到文件」** 即可保存到 iCloud 云盘或手机本地。需要恢复时在「设置」里导入该 JSON 文件即可。
- **数据仅存本机**：所有数据只存在这台手机上。如果在 Safari 设置里**清除网站数据**（或抹掉手机），Panda 里的记录会**一并被删除且无法找回**——所以请养成定期导出备份的习惯。

## 🛠 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本（产物在 dist/）
npm run build
```

技术栈：Vite + React + TypeScript + Dexie (IndexedDB) + vite-plugin-pwa
